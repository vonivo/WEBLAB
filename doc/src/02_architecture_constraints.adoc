[[section-architecture-constraints]]
== Randbedingungen

Ein grossteil der Randbedingungen können aus den Projekt-Anforderungen abgeleitet werden.

=== Technische Randbedingungen

|===
|Randbedingungen |Erklärung

|Mobile/Tablet-optimiert
|Die Applikation soll neben der Desktop-Ansicht, auch für die Mobile/Tablet-Ansicht optimiert sein.

|Automatisiertes Testing
|Die Funktionalitäten sollen mittels sinnvollen automatisierten Unit/Integration/E2E-Tests überprüft werden.

|Performance
|Lighthouse-Score von mindestens 90 (Durchschnitt aller Analysen) für Mobile sowie Desktop.

|Reproduzierbarer Prod-Start
|Das Prod-Bundle der Applikation soll reproduzierbar gestartet werden können.

|Genutzte Technologien
| Für die Implementation des Backends sowie Frontends soll JavaScript oder TypeScript genutzt werden.
|===

=== Organisatorische Randbedingungen

|===
|Randbedingungen |Beschreibung

|Hosting
|Das Repository wird auf GitHub gehostet.

|Verwendung von AI
|Verwendung von AI (Agents) ist erlaubt

|Zeitaufwand
|Es soll ca. ein Zeitaufwand von ca. 60h Arbeit investiert werden.
|===
