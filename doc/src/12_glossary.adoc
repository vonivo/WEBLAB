[[section-glossary]]
== Glossar

[cols="e,2e" options="header"]
|===
|Begriff |Definition

|SPA
|Single-Page-Application. UI wird einmal geladen und dann clientseitig gerendert.

|PWA
|Progressive Web App: Web-Applikation die auf Mobile-Geräten installiert werden können und gewisse Native-Funktionalitäten unterstützen.

|ADR
|Architecture Decision Record: Hält eine getroffene Architekturentscheidung fest.

|Lighthouse
|Analyse-Tool für Web-Performance und Best-Practices von Google.
|===
