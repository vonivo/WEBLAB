== Kontext und Abgrenzung
=== Business Kontext
image:KontextDiagram.png[]

==== Admin Benutzer
Der Admin Benutzer ist für die Erfassung der Teams, Games und Events (Goals, Kickoff etc.)
zuständig.

==== User
Der Benutzer ruft die Webseite auf und erhält eine SPA wo er dann Informationen zu Games abrufen kann.

=== Technischer Kontext
[plantuml, architecture, svg]
----
@startuml
skinparam componentStyle rectangle
skinparam shadowing false

actor "Benutzer" as user

rectangle "Live Ticker System" as system {

    component "Web-Frontend" as frontend
    component "Backend / REST API" as backend
    database "Datenbank" as database

    frontend --> backend : HTTP / REST
    backend --> database : Datenzugriff
}

user --> frontend : HTTP / HTTPS

@enduml
----
Das Live-Ticker-System besteht aus einer webbasierten Benutzeroberfläche, einem Backend mit REST-API sowie einer persistenten Datenhaltung. Der Benutzer greift über einen Webbrowser auf das Frontend zu. Dieses kommuniziert über HTTP mit dem Backend, welches die Geschäftslogik verarbeitet und auf die Datenbank zur Speicherung und Abfrage der Anwendungsdaten zugreift.
